# Tema 02

## Qué he hecho

He creado dos páginas usando Bootstrap.

En `index.html` he puesto una tabla con Chrome, Firefox, Safari, Edge y Opera.
También explico qué motores utilizan y por qué es importante probar una web
en distintos navegadores.

En `interaccion.html` he creado tres botones con JavaScript.

- **Saludar:** muestra un mensaje con `alert()` y escribe en la consola.
- **Simular un error:** escribe un error con `console.error()`.
- **¿Qué navegador soy?:** muestra `navigator.userAgent` en un `alert()` y en la consola.

El código JavaScript está separado en `js/app.js`.

## Quién hace qué

En el botón **Saludar**:

- HTML crea el botón.
- Bootstrap le da estilo.
- JavaScript hace que al pulsarlo salga un mensaje y se escriba una traza en la consola.
