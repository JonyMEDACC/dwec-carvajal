Explicación

Chrome, Edge y Opera comparten Chromium y usan Blink, por eso muchas paginas funcionan de forma parecida en ellos. Firefox utiliza Gecko y Safari utiliza WebKit. Esto es importante porque una misma web puede verse o funcionar de forma diferente según el navegador. Por eso conviene probar una página en varios navegadores, sobre todo si usan motores distintos.

Ejemplo de compatibilidad

Una característica moderna de CSS puede no funcionar igual en todos los navegadores. Un ejemplo es CSS Anchor Positioning.

Reflexión

Primero probaría la web en Chrome y Firefox porque utilizan motores distintos. También la probaría en Safari si se va a usar en iPhone o Mac. También comprobaría que se vea bien en móvil usando el modo dispositivo del navegador.
